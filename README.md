# EventiX - High Concurrency Event Ticketing Platform

Dự án Hệ thống Phân phối và Quản trị Vé Sự kiện Chịu Tải Cao (Concert, Sân vận động).

## 🚀 Tech Stack hiện tại
- **Backend:** Java 21, Spring Boot 3.3.x, Spring Security (JWT)
- **Database & Cache:** PostgreSQL 16, Redis 7, Flyway Migration
- **Message Broker:** RabbitMQ
- **DevOps:** Docker Compose
